# Review methodology

RecallForge optimizes for retrieval and correction, not passive rereading. Start with the learner's material, reconstruct the smallest useful topic map, identify distinctions and prerequisites, and test before re-explaining where possible.

Prioritize a topic only with a stated reason: supplied exam signals, material emphasis, prerequisite value, time available, or demonstrated learner difficulty. When evidence is missing, say what is unknown instead of converting a heuristic into a fact.

Use short cycles: map → recall → answer → diagnose → targeted retry. Ask one question at a time unless the learner requests a full mock exam.
