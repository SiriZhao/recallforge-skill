# 资料指南

## PPTX

原生路径读取幻灯片顺序、标题、文本框、原生表格、演讲者备注，并把图片/图表和空间坐标保留为块。包含箭头、流程、对比、公式或图片时，在宿主支持的情况下还应渲染整页做视觉理解。原生文字和视觉解释会融合，不能互相替代。旧式二进制 `.ppt` 尚未实现。

## 数字 PDF

逐页判断。可靠文字和布局块走快速路径；包含大量图片、公式、旋转、可疑乱码或试卷结构的页面进入视觉验证。不会因为一页扫描件就 OCR 整本 PDF。

## 扫描 PDF 与图片

纯图片页优先交给宿主视觉。Python 工具包中可选的 Tesseract OCR 只作为低置信度后备，默认关闭。OCR 文字不能替代图示关系、化学结构、手写批注角色或表格布局。

## 往年试卷

在能够提取时，统一结构会区分题号、题干、选项、小题、配图、分值、印刷答案和用户/未知批注。手写的 `B` 不会自动当作标准答案。

## 公式与表格

公式保留原始表示、解释结果、上下文、置信度和来源；多路识别冲突时标记 uncertain。表格保留表头、行和单元格；结构恢复失败会报告，不会静默压平。

## 图示密集课程

有机结构式、反应箭头、细胞图、花程图、解剖、形态、曲线和流程图会保留为视觉概念。标签或关系不清时，请提供高清局部图。

## 大量资料

先建立资料目录和结构扫描，再构建课程地图，只对高优先级片段深入处理。同一对话中新资料可增量合并；跨会话持久性取决于宿主，安装的 Skill 不承诺长期记忆。

## 缓存与重复资料

纯 Skill 不会创建自己的缓存。可选 Python 工具包会在指定 workspace 的课程 evidence store 中记录文件 SHA-256 和证据内容哈希，以跳过未变化文件和重复证据。显式配置 `cache_dir` 时，还会按文件哈希、页/幻灯片、处理级别和 DPI 缓存渲染页。只有确认要重新摄取时才删除自己指定的缓存目录或 workspace 证据文件；不要删除整个 Skills 目录。
