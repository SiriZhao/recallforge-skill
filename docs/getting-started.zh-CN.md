# 入门

1. 从 [Releases](https://github.com/SiriZhao/recallforge-skill/releases/latest) 下载 `recallforge-skill-v2.1.0.zip`。
2. 解压后应只看到一个 `recallforge` 文件夹。
3. Windows 复制到 `%USERPROFILE%\.agents\skills`；macOS/Linux 复制到 `~/.agents/skills`。
4. 开启新的 Codex 对话并输入 `$recallforge self-test`。
5. 出现 `Status: READY` 后，粘贴笔记或上传已授权资料，使用 README 的首次复习 Prompt。

仅在一个项目使用时，将文件夹放到 `<项目>/.agents/skills/`。各系统安装、更新和卸载请看[Codex 教程](codex.zh-CN.md)。
