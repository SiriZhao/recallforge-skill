# 多模态资料

RecallForge 会融合多路证据，而不是把 OCR 等同于多模态理解。

- **文字：**优先可靠的原生提取。
- **扫描件：**渲染页面并使用宿主视觉；OCR 只是可选后备。
- **表格：**保留表头、行、列和单元格。
- **公式：**保留原始表示、解释结果、周边语境、置信度和来源。
- **图示：**保留标签、分组、箭头、图例、空间关系和视觉对比。
- **手写：**标记为用户或未知批注，不作为已验证答案。

处理分为快速、标准和精细三级。精细处理只用于低置信度扫描、多栏试卷、复杂公式、化学结构、手写和多路识别冲突。

宿主视觉不可用时，可靠原生内容仍可使用，视觉块会被标记 unresolved。可选 Python OCR 默认关闭；它只能恢复部分文字，不能把图片自动变成完整理解的图示。

真实宿主能力边界请运行[人工验收](manual-verification.zh-CN.md)。
