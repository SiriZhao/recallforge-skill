# Why RecallForge?

| Capability | Generic chat | PDF summarizer | Flashcard generator | RecallForge |
|---|---|---|---|---|
| Raw material intake | Prompt-dependent | Usually PDF/text | Usually prepared text | Catalog + page/slide routing |
| Visual material | Host-dependent | Often text-first | Rarely central | Host vision path with uncertainty |
| Knowledge reconstruction | Optional | Summary outline | Card grouping | Exam-focused topic structure |
| Active recall | Optional | Usually no | Yes | One-question diagnostic loop |
| Weakness adaptation | Conversation-dependent | No | Often scheduling only | Based on learner answers |
| Past-paper grounding | Manual | Text extraction | Rare | Question structure + source anchors |
| Source traceability | Optional | Sometimes page citations | Rare | Preserved internally by default |
| Mock exam and repair | Prompt-dependent | No | Limited | Withheld answers → grade → repair |

This comparison describes workflows, not universal limits of other tools. RecallForge’s value is a repeatable material-to-adaptive-review process—not a promise of mastery or exam results.
