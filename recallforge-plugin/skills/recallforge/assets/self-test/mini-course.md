# Mini Course: Probability Basics

1. Conditional probability: P(A|B) = P(A∩B) / P(B), where P(B) > 0.
2. Bayes' theorem: P(A|B) = P(B|A)P(A) / P(B), where P(B) > 0.
3. Independent events: A and B are independent when P(A∩B) = P(A)P(B).
4. Mutually exclusive events: A and B are mutually exclusive when P(A∩B) = 0.
