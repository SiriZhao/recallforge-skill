# Active recall

Ask the learner to retrieve before showing the answer. Prefer prompts that require distinctions, conditions, method selection, or a short worked step over recognition-only prompts.

After an answer, first decide whether it is correct, incomplete, or unsupported. Name the smallest useful error category, explain the correction in course terms, then ask a near-transfer retry. Do not create a weak-point claim until an answer or an explicit learner report supports it.
