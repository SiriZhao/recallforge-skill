# Probability & Statistics

**Learning objective:** reconstruct core probability concepts, connect a past-paper style question to its topic, and use active recall to check assumptions.

**Input:** a small self-authored note such as `examples/input/lecture_sample.txt`, plus an authorized past-paper excerpt if available.

**Workflow:** initialize a `probability` course, ingest the input, build the course model, inspect `material-report`, then run `tutor`, `quiz --mode past-exam-style`, and `answer`.

**Expected output structure:** evidence-linked topic names; source-supported exam points; a priority/risk rationale; recall questions; and, after a real incorrect answer, a wrongbook item plus a revised plan. No readiness score is expected before real answers exist.
