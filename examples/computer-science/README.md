# Computer Science

**Learning objective:** turn algorithm and data-structure notes into recall prompts and a time-aware review plan.

**Input:** small self-authored notes such as complexity summaries, lecture outlines, or authorized practice questions. Do not include proprietary assignments or student submissions.

**Workflow:** build a `computer-science` course, run `workspace diagnostic --minutes 15`, study a selected topic with `tutor`, then record real answer outcomes and rerun `plan-v4`.

**Expected output structure:** topic priorities with evidence, diagnostic items, adaptive question modes, and a plan that treats unknown mastery as unknown rather than assuming weakness or strength.
