# Biology

**Learning objective:** organize processes, terminology, and common confusions for repeated active recall.

**Input:** a small self-authored botany or biology note, a syllabus, and authorized past-paper excerpts where available.

**Workflow:** create a `biology` course, ingest files, build the knowledge/exam model, quiz a topic, then use `report --type wrongbook` and `cram --mode 1h` before review.

**Expected output structure:** an evidence-grounded knowledge map, topic relationships, recall prompts, wrong-answer repairs, and an exam-focused cram list. It will not invent teacher preferences or past-paper frequency without supporting material.
