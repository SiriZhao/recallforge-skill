# Organic Chemistry

**Learning objective:** connect reaction conditions, mechanisms, and common traps without treating a generic summary as evidence.

**Input:** self-authored lecture notes or authorized reaction sheets in TXT; optional document ingestion can be installed for other supported formats.

**Workflow:** create an `organic-chemistry` course, ingest material, build the model, request `quiz --mode weak-topic`, and use `cram --mode 3h` near the exam.

**Expected output structure:** course-scoped reaction topics, evidence references, condition-focused active-recall prompts, real-answer diagnosis, and targeted next review. If a formula or scan cannot be verified, RecallForge should mark it unresolved or low confidence.
