# Code of Conduct

## Our Pledge

We want exam-review-skill to be a welcoming project for students, educators, and developers.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent.
- Give clear feedback without personal attacks.
- Respect privacy, copyright, and academic integrity.

## Unacceptable Behavior

- Harassment, discrimination, or abusive language.
- Sharing private student data or restricted exam materials.
- Encouraging cheating or violation of school rules.
- Publishing secrets, API keys, or personal information.

## Enforcement

Maintainers may remove comments, close issues, or block participants who violate this code of conduct.
